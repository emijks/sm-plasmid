```
cd sm-plasmid
python3 plasmid.py -x path_to_xlsx -t path_to_tmp -s path_to_fastq -r path_to_ref -o path_to_results -f 2
```

# Статус-таблица
После выполнения всех стадий скрипт ```make_status-table.py``` создает статус-таблицу следующего формата

|Столбец|Описание|
|-------|--------|
|sample|Идентификатор образца|
|reference|Статус наличия референсной последовательности|
|fastq|Статус наличия парных FASTQ-файлов|
|assembly|Статус сборки|
|bam|Статус выравнивания|
|bam_index|Статус индексирования BAM|
|variant_calling|Статус вариант-коллинга|
|snp_count|Количество обнаруженных SNP|
|indel_count|Количество обнаруженных инделов|
|consensus|Статус консенсусной последовательности|
|report|Статус итогового HTML-отчёта|

Какие бывают статусы:
- **MISSING** ожидаемый файл отсутствует; для входных данных означает отсутствие референса или FASTQ-файлов
- **EMPTY** файл существует, но имеет нулевой размер
- **INVALID** файл присутствует, но имеет некорректный формат (например, FASTA не содержит последовательностей)
- **OK** этап успешно выполнен, файл существует и имеет корректный формат
- **SKIPPED** этап не выполнялся, поскольку отсутствовали необходимые входные данные (например, референс или FASTQ-файлы)
- **NO_VARIANTS** файл вариантов создан, однако SNP и инделы не обнаружены.
